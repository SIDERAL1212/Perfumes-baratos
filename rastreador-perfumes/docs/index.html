Conexão com o GitHub

Com a conexão, este site salva a lista de perfumes no seu repositório e dispara uma leitura de preços quando você pedir. Sem ela, você ainda vê o painel e pode copiar o JSON para colar no GitHub.

  1. No GitHub, abra Settings → Developer settings → Personal access tokens → Fine-grained tokens e clique em Generate new token.
  2. Em Repository access, escolha Only select repositories e marque só o repositório do rastreador.
  3. Em Permissions → Repository permissions, coloque Contents: Read and write e Actions: Read and write.
  4. Gere o token, copie e cole acima. Ele fica guardado só neste navegador e é enviado apenas ao GitHub.
